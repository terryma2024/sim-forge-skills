# 验证范围与证据

2026-10-14 的验证使用已有的真实 Seed3D 模型，避免为了测试 Skill 重复付费。它经过新入口重新导入、重拓扑、烘焙、导出与实际 Isaac 执行；并非仅复制旧流程的最终成功标记。

## 已通过

- 官方 Skill quick_validate 格式检查。
- 新客户端通过 `adopt-task` 实际查询了之前成功的 Ark 任务，返回 succeeded；没有创建新收费任务。
- Python 标准库单元测试：确认绑定实际产物哈希、确认缺失产物会拒绝；端到端缺图返回明确输入请求；SSH 目的地变更不能复用授权；未知提交不重复创建任务；Key 不存在时不伪记为已提交；4xx拒绝与未知结果区分；ZIP只读取唯一GLB成员；exit=0不能替代实际物理 `passed=true`。
- Blender 5.2.2 LTS / Metal 实测：固定原版 SimForge commit `b80ae50f5f6d8ec4353d8374dce972744e5a233a`；50万三角面导入生成3D预览；8,949四边形低模、UV、0非流形边；2048px五通道烘焙；USD质量、单位、材质、相对资源与两方案几何一致性验收。
- Isaac Sim 6.0.1.0 / Linux NVIDIA RTX 实测：新脚本生成场景并运行两组动态杯子/球；120Hz固定时间步、CCD，600轨迹点/组，150实际RGB帧。首轮45秒观察窗口结束后返回 `simulation_running`，下一次run取回同一个远端尝试，最终 `complete`；没有重复启动。
- 实际最终帧人工检查：左球在杯腔，右球在杯口上方；两杯保持落地。FFprobe核验H.264、1280×720、150帧、5秒，源GLB和烘焙贴图校验均通过。
- 普通 `drop` 模式也在同一真实资产上运行：不创建小球，两个动态资产分别下落约45mm，最后半秒三维位移为0，`passed=true`；取得150帧/5秒真实视频。
- 独立代理应用测试：参考图和模型接受后，重复run/default run均停在 `awaiting_review/blender`，不启动额外worker或远端任务；Mac无输入时准确返回缺图状态。GLB无参考图可实际导入/渲染并停在 `model`；复制固定源码缓存后bootstrap和资产收据恢复通过。测试未修改原始运行目录，全部262个原文件哈希保持一致。

## 限制

环境doctor是发现信息，不等于GPU或Isaac通过。GitHub CI仅测试11项标准库状态协议，不运行付费生成、Blender或NVIDIA仿真。Seed3D新的创建请求尚未为验证Skill而付费重跑；已有真实源模型和实际API任务来自此前完整复现，当前客户端的查询/恢复经过真实API检查，请求边界经过本地测试。

杯子对照显式使用两组相同的角阻尼300/s；默认通用配置不采用此值。当前证据证明指定模型/参数的碰撞演示，不证明任意AI模型、其他软件版本、真实材料标定或机器人抓取性能。自然语言到参考图依赖代理的图像工具，CLI要求已有图像。
